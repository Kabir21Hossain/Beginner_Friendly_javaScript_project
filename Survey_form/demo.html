United Nations COVID-19 Health Survey

Collect data on health impacts and antiviral usage across countries during the coronavirus pandemic.

About This Project

This is a multifunctional web project built with HTML, CSS (via Tailwind), and JavaScript. It demonstrates various form features including inputs, selects, checkboxes, radios, textareas, validation, dynamic elements, and more. The theme focuses on a UN survey for COVID-19 health data, including antiviral information from different countries.

Features include:

  • Multiple form types (user info, survey submission)
  • Form validation (required fields, patterns, min/max)
  • Dynamic form elements (add/remove antiviral entries)
  • Local storage for saving and displaying submitted data
  • Accessible and responsive UI with Tailwind CSS
  • Event handling in JavaScript (submit, change, etc.)
